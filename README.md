# Toolbox

Browser-native utilities that run entirely on your device. No server, no tracking, no signup — your data never leaves the page.

**Try it now →** https://sierralx.github.io/Toolbox/

Single HTML file. No dependencies. No build step. Just open `index.html` or bookmark the link above.

---

## Tools

| Tab | What it does |
|-----|--------------|
| **JSON** | Validate, pretty-print and minify JSON, with clear error messages |
| **Base64** | Unicode-safe encode / decode (emoji included) |
| **URL** | Percent-encode / decode text and URLs |
| **UUID** | Generate cryptographically random v4 UUIDs, one or ten at a time |
| **Timestamp** | Unix timestamp ⇄ date, two-way; auto-detects seconds vs milliseconds |
| **Text** | UPPER/lower/Title case, sort lines, remove duplicates, trim lines, remove empty lines, live word/char/line stats |

Every tool has one-click **copy** buttons. Tabs are deep-linkable (`#json`, `#base64`, …).

## Privacy

Everything runs locally in your browser with vanilla JavaScript. Nothing is sent anywhere — there is no backend to send it to.
